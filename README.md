# ATC — Actions Traffic Control

A real-time dashboard for monitoring GitHub Actions workflows across your organization.

> **Status:** Under construction. The repository is bootstrapped with tooling and conventions; application code is coming in subsequent phases.

## What is ATC?

ATC provides a unified, real-time view of GitHub Actions workflows — like air traffic control for your CI/CD pipelines. Monitor runs, spot bottlenecks, and catch failures across all your repositories from a single dashboard.

## Quick Start

```bash
# Prerequisites: mise (https://mise.jdx.dev)
just setup    # Install all tools and dependencies
just dev      # Start development servers
```
