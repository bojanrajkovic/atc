# Human Test Plan — App Shell

## Prerequisites

- Development environment running: `pnpm dev` from `frontend/`
- All automated tests passing: `just test` from project root
- A modern browser (Chrome, Firefox, or Safari) at `http://localhost:5173`

## Phase 1: App Shell Layout

| Step | Action | Expected |
|------|--------|----------|
| 1 | Open `http://localhost:5173`. Resize window to various heights (short: 400px, normal: 900px, tall: 1200px). | App shell fills full viewport height. No scrollbar on page body. TopBar pinned at top. |
| 2 | With a short viewport (400px), verify the content area below TopBar is scrollable if content overflows. | TopBar remains fixed at top. Content area scrolls independently. |

## Phase 2: Logo and Branding

| Step | Action | Expected |
|------|--------|----------|
| 1 | Look at the top-left of the TopBar. | "ATC" text displayed in a monospace font. |
| 2 | Right-click the "ATC" text, Inspect Element. | Element has `aria-label` containing "Actions Traffic Control". |

## Phase 3: Connection Indicator States

| Step | Action | Expected |
|------|--------|----------|
| 1 | Open app without the backend running. | Blue dot with pulsing animation (connecting state). |
| 2 | Start the backend server. Wait for connection. | Dot turns green with subtle glow (live state). |
| 3 | Stop the backend. Wait ~30 seconds. | Dot transitions amber (stale), then red (disconnected). |
| 4 | Restart the backend. | Dot transitions through blue (connecting) back to green (live). |

## Phase 4: Connection Indicator Tooltip (AC2.8 — Manual Required)

| Step | Action | Expected |
|------|--------|----------|
| 1 | With backend running (live state), hover over the green dot. | Tooltip shows "Connected". |
| 2 | Stop backend. Wait for amber (stale). Hover. | Tooltip shows "No events for Xs". |
| 3 | Wait for blue (connecting). Hover. | Tooltip shows "Reconnecting..." or similar. |
| 4 | Wait for red (disconnected). Hover. | Tooltip shows "Disconnected". |
| 5 | On each hover, verify tooltip appears promptly (~200ms), is readable, disappears on mouse leave. | Smooth, non-flickering behavior. |

## Phase 5: Runner Bar and Pool Indicators

| Step | Action | Expected |
|------|--------|----------|
| 1 | Open app without backend. | "No pools" text in runner bar area. |
| 2 | Start backend with webhook data flowing. | Pool indicators appear with labels, counts, and capacity bars. |
| 3 | Verify a pool with known capacity (`total` not null). | Capacity bar visible. Fill color: green (<70%), amber (70-99%), red (100%). Count shows "N/M". |
| 4 | Verify a pool with unknown capacity (`total` null, not elastic). | No capacity bar. Running count only. |
| 5 | Verify an elastic pool (`isElastic` true). | No capacity bar. Running count without denominator. |
| 6 | Trigger queued jobs. | "+N queued" badge appears. Disappears when queued drops to 0. |

## Phase 6: Settings Popover and Theme Switching

| Step | Action | Expected |
|------|--------|----------|
| 1 | Click gear icon in top-right. | Popover opens with theme dots, mode toggle, density toggle. |
| 2 | Click "warm" theme dot. | Colors update. `data-theme="warm"` on `<html>`. |
| 3 | Click "violet" theme dot. | Colors update. `data-theme="violet"`. |
| 4 | Toggle light mode switch. | UI switches between dark/light. |
| 5 | Toggle compact density switch. | Spacing tightens (compact) or relaxes (comfortable). |
| 6 | Refresh page. | Preferences persist (localStorage). |
| 7 | Click outside popover. | Popover closes. |

## Phase 7: ConnectionManager Lifecycle (AC5.1-5.3 — Documented Gap)

| Step | Action | Expected |
|------|--------|----------|
| 1 | Open app with DevTools Network tab (WebSocket filter). | WebSocket to `/v1/ws` initiated on load (AC5.1). |
| 2 | Navigate away or close tab. Check WebSocket status. | Connection cleanly closed (AC5.2). |
| 3 | Inspect DOM for ConnectionManager. | No visible DOM elements (AC5.3). |

## End-to-End: Full Lifecycle Scenario

1. Start backend. Open `http://localhost:5173` in clean browser profile.
2. Verify app fills viewport, TopBar pinned, content area visible.
3. Verify "ATC" logo, connection indicator turns green, "No pools" shows.
4. Trigger webhook events. Verify pools populate with correct indicators.
5. Hover connection indicator — verify tooltip.
6. Open settings, switch to "warm" theme, toggle light mode. Verify changes.
7. Refresh page. Verify persistence. Verify WebSocket reconnects and pools refresh.
8. Stop backend. Verify indicator transitions stale → disconnected.
9. Restart backend. Verify indicator returns to live and pools refresh.
